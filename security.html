Security Practices

Last Updated: January 15, 2025

DataCaboose is committed to maintaining the highest standards of security for our Canadian cloud infrastructure. This document outlines our comprehensive security practices, compliance frameworks, and ongoing efforts to protect your data and infrastructure.

🛡️ Security First: Our multi-layered security approach ensures your data remains protected in our Canadian data centers with zero-trust architecture and continuous monitoring.

1. Infrastructure Security

Physical Security

  • 24/7 on-site security personnel
  • Biometric access controls
  • CCTV monitoring with 90-day retention
  • Environmental monitoring systems
  • Redundant power and cooling systems

Network Security

  • Next-generation firewalls (NGFWs)
  • Intrusion detection and prevention (IDS/IPS)
  • DDoS protection (up to 100 Gbps)
  • Network segmentation and VLANs
  • Regular penetration testing

Compute Security

  • Hypervisor hardening and isolation
  • Secure boot and attestation
  • Hardware security modules (HSMs)
  • Memory protection mechanisms
  • VM escape prevention

Data Security

  • AES-256 encryption at rest
  • TLS 1.3 encryption in transit
  • Key management service (KMS)
  • Secure data destruction
  • Data loss prevention (DLP)

2. Access Control and Identity Management

2.1 Authentication and Authorization

  • Multi-Factor Authentication (MFA): Required for all administrative access
  • Single Sign-On (SSO): Integration with enterprise identity providers
  • Role-Based Access Control (RBAC): Principle of least privilege
  • Privileged Access Management (PAM): Secure access to critical systems
  • Just-in-Time Access: Temporary elevated privileges with approval workflows

2.2 User Account Security

  • Strong Password Policies: Minimum 12 characters with complexity requirements
  • Account Lockout Protection: Automated protection against brute force attacks
  • Session Management: Automatic timeout and secure session handling
  • API Key Management: Secure generation, rotation, and revocation
  • Certificate-Based Authentication: X.509 certificates for service accounts

3.2 Data Residency and Sovereignty

🍁 Canadian Data Sovereignty Guarantee: All customer data remains within Canadian borders, protected under Canadian privacy laws.

  • Geographic Restrictions: Data never crosses international borders
  • Legal Jurisdiction: All data processing governed by Canadian law
  • Foreign Access Protection: Immunity from foreign surveillance laws
  • Data Location Transparency: Real-time data location reporting
  • Repatriation Services: Secure migration from foreign cloud providers

6. Customer Security Responsibilities

6.1 Shared Responsibility Model

Security is a shared responsibility between DataCaboose and our customers:

DataCaboose Responsibilities

  • Physical infrastructure security
  • Hypervisor and host OS security
  • Network infrastructure protection
  • Data center environmental controls
  • Service platform security

Customer Responsibilities

  • Guest operating system security
  • Application-level security
  • User access management
  • Data classification and encryption
  • Network traffic protection

6.2 Security Best Practices for Customers

  • Regular Updates: Keep operating systems and applications current
  • Strong Authentication: Implement MFA for all user accounts
  • Network Segmentation: Use security groups and firewalls effectively
  • Data Backup: Regularly backup critical data with encryption
  • Monitoring: Implement application and system monitoring

7. Business Continuity and Disaster Recovery

7.1 Business Continuity Planning

  • Redundant Infrastructure: N+1 redundancy across all critical systems
  • Geographic Distribution: Multi-region deployment across Canada
  • Automated Failover: Zero-touch failover for critical services
  • Regular Testing: Quarterly disaster recovery exercises
  • Recovery Objectives: RTO < 4 hours, RPO < 1 hour

7.2 Data Backup and Recovery

  • Automated Backups: Daily incremental, weekly full backups
  • Cross-Region Replication: Backups stored in multiple Canadian regions
  • Encryption: All backups encrypted with separate key hierarchy
  • Retention Policies: Configurable retention from 30 days to 7 years
  • Recovery Testing: Monthly backup integrity verification
